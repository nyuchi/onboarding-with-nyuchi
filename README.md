## What it is

This repository was created on 3 June 2025 in a single three-commit burst —
initial commit, GitHub's default issue templates, and a `FUNDING.yml` — and
then left alone. Nothing was ever added. Its entire tree is an MIT `LICENSE`,
the two default issue templates, `FUNDING.yml`, the shared lint configuration,
and this file.

The name suggests it was meant to hold onboarding material for people or
clients starting work with Nyuchi. That is a guess from the repo slug and
nothing more: the repository has no description, no topics, no homepage, no
issues, no pull requests, and no commit message that explains it. Nothing
anywhere else in the estate links to it or refers to it.

This README says so rather than inventing a purpose, because a plausible
description here would be indistinguishable from a true one and would outlive
the ability to tell them apart.

**If you know what this repo was for**, replace this file with the real thing.
**If nobody does**, it should be archived — an empty repository that survives
long enough starts to look like a project that stalled rather than one that
never began.
